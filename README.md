# 🏦 ByteBank ATM - Simulador de Caixa Eletrônico

![Python](https://img.shields.io/badge/Python-3670A0?style=for-the-badge&logo=python&logoColor=ffdd54)
![Ubuntu](https://img.shields.io/badge/Ubuntu-E95420?style=for-the-badge&logo=ubuntu&logoColor=white)

Um sistema completo de simulação de Caixa Eletrônico (ATM) com interface gráfica, desenvolvido em **Python** e **Tkinter**. 

Este projeto foi desenvolvido como um trabalho acadêmico com o objetivo de integrar e compor uma **remasterização customizada do Linux Ubuntu 26 LTS**. O sistema foi projetado para rodar em modo Kiosk (tela cheia bloqueada), ideal para terminais de autoatendimento.

## 🚀 Funcionalidades

O sistema conta com um ecossistema visual inspirado no design system de grandes bancos e oferece as seguintes operações:

- **Autenticação Segura:** Login utilizando número da conta e senha numéricas.
- **Saques e Depósitos:** Movimentação financeira com validação de saldo e limites.
- **Transferências:** Envio de valores entre contas cadastradas no sistema.
- **Extrato Dinâmico:** Visualização do histórico de transações e saldo em tempo real.
- **Geração de Recibos:** Emissão automática de comprovantes em formato `.txt` após cada transação financeira.
- **Kiosk Mode & Segurança:** Bloqueio inteligente de tela cheia no Linux e timer automático de inatividade (timeout) que encerra a sessão após 30 segundos sem uso.
